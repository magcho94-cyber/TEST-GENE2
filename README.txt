JONG-RO M ENGLISH TEST STUDIO v2.1 GALAXY GREY

핵심 화면은 WEEKLY TEST / SIMUL TEST 두 개입니다.

WEEKLY TEST
- 중1~고3
- BE동사부터 관계사/가정법/도치/분사구문 등 문법 개별 선택
- 문법 문제 형식 개별 선택
- 수업 지문 기반 출제
- 일반 모의고사 PDF/텍스트 입력 후 유형별 변형 출제

SIMUL TEST
- 학교/학년/시험 설정
- 학교 기출 PDF 분석
- 이번 시험범위 지문 입력
- 학교 기출 문항 형식에 맞춘 새 문제 생성
- 수능/모의고사 전 유형 + 내신형 + 문법 유형 개별 선택
- 기존 출제 이력 DB와 비교해 재출제 억제

디자인
- WEEKLY TEST: GREY 표지 + 듣기/문법/독해/해석 점수칸 (총점/전체 문항수 표기 없음)
- SIMUL TEST: GREY 표지 + 점수칸 없음
- 내지: 심플 라인형 / 좌우 2단 / 중앙 세로 구분선
- 브라우저 인쇄 기능으로 PDF 저장 가능

Render 환경변수
OPENAI_API_KEY=...
DATABASE_URL=... (선택, 없으면 실행 중 임시 이력)
OPENAI_MODEL=gpt-5.6-luna (선택)

실행
npm install
npm start
